# 08 数据导出方案（CH376 读 U 盘）

> 状态：**方案已确认（方案 B），暂不实施**
> 日期：2026-08-21
> 变更记录：原方案 A（STM32 模拟 U 盘 MSC）设计完成后，经用户评估改为**方案 B（CH376 USB 主机，插真实 U 盘导出）**。方案 A 作为备选保留在文末。

---

## 1. 方案概述

**最终形态**：板载 USB-A 母座，插入真实 U 盘后，STM32 通过 CH376 把 W25Q16 中记录的浓度数据**写入 U 盘**，生成 `LOG.CSV`。现场即插即导，**无需电脑**。

**为什么不用 STM32 直接读 U 盘**：STM32F103C8T6 的 USB 外设只有 **Device（设备）模式**，没有主机（Host）控制器——这是芯片硬限制。因此加一颗 **CH376**（沁恒 USB 主机接口芯片，**内置 FAT16/FAT32 文件系统**），STM32 通过 SPI 指挥它读写 U 盘，等于"借用"CH376 当 USB 主机。

**数据流**：

```
W25Q16（记录数据）
   ↓ SPI1 读取
STM32F103（数据搬运）
   ↓ SPI1 指令
CH376（USB 主机 + FAT）
   ↓ USB
U 盘 → LOG.CSV（可带走，可清空板内 Flash 继续记录）
```

## 2. 硬件设计（11 个器件）

### 2.1 器件清单

| 位号 | 器件 | 规格/封装 | 作用 |
|------|------|----------|------|
| U7 | CH376T | TSSOP-20（SPI 版） | **USB 主机 + 内置 FAT16/32** |
| J6 | USB-A 母座 | 4P 直插/贴片 | U 盘插口 |
| X2 | 晶振 | **12MHz**（CH376 专用） | CH376 时钟（非系统 8MHz） |
| C15 | 贴片电容 | 100nF 0603 | V3 引脚稳压 |
| C16 | 贴片电容 | 10uF 0603 | VCC 低频去耦 |
| C17 | 贴片电容 | 100nF 0603 | VCC 高频去耦 |
| C18 | 贴片电容 | 22pF 0603 | 晶振负载 |
| C19 | 贴片电容 | 22pF 0603 | 晶振负载 |
| C20 | 电解电容 | 470uF/10V | **VBUS 浪涌缓冲**（U 盘插入瞬间） |
| C21 | 贴片电容 | 100nF 0603 | RSTI 复位电容 |
| R15 | 贴片电阻 | 10kΩ 0603 | RSTI 上拉（VOUT5→RSTI） |

> 位号接续：U7（U1-U6 已用）、J6（J1-J3 已用，J5 弃用）、X2（X1 为系统晶振）、C15-C21（C1-C13 已用）、R15（R1-R14 已用）。方案 A 的 J5/R16/R17/C14 不再使用。

### 2.2 引脚连接

#### CH376 → STM32（SPI 控制）

| U7 引脚 | 网络名 | 连到 | 说明 |
|---------|--------|------|------|
| SCS | `CH_CS` | **PB12** | 片选（GPIO 输出） |
| SCK | `SPI_SCK` | **PA5** | **与 W25Q16 共用 SPI1** |
| SDI | `SPI_MOSI` | **PA7** | 共用 SPI1_MOSI |
| SDO | `SPI_MISO` | **PA6** | 共用 SPI1_MISO |
| INT# | `CH_INT` | **PB13** | 中断输入（PB13 配置为输入上拉，免外部电阻） |

#### CH376 → U 盘（USB）

| U7 引脚 | 网络名 | 连到 | 说明 |
|---------|--------|------|------|
| UD+ | `USB_DP` | J6.DP | USB 数据正 |
| UD- | `USB_DM` | J6.DN | USB 数据负 |
| VCC | `VOUT5` | 5V 总线 | CH376 必须 5V 供电 |
| GND | `GND` | 地 | 共地 |

#### CH376 辅助

| U7 引脚 | 连到 | 说明 |
|---------|------|------|
| V3 | C15(100nF) → GND | 内部稳压电容 |
| X1 / X2 | X2 晶振 12MHz + C18/C19(22pF) | 专用时钟 |
| RSTI | R15(10k) → VOUT5；C21(100nF) → GND | 上电自动复位（RC） |
| ACT# | 悬空（可选接 LED 指示） | 可选 |

### 2.3 关键说明

- **SPI1 总线复用**：W25Q16（片选 PA4=SPI_CS）与 CH376（片选 PB12=CH_CS）共用 SCK/MOSI/MISO，从机分时操作，软件片选切换即可，Flash 模块不用改。
- **电平匹配**：CH376 为 5V 供电，SPI 引脚与 STM32 直连安全——PA5/PA6/PA7/PB12/PB13 均为 **5V 容忍（FT）引脚**。
- **U 盘供电**：J6.VBUS 接 VOUT5，C20(470uF) 缓冲插入浪涌。注意 MT3608 总负载：系统 + U 盘约 200~300mA，在升压能力范围内。
- **PA11/PA12**：保持悬空（方案 A 已弃用），建议放 NC 标记消除 ERC 警告。

## 3. 软件设计

### 3.1 指令流程（CH376 内置 FAT，无需 FatFs）

```
1. SPI 初始化 + CH376 复位（RSTI 拉低 >30us 再拉高）
2. 轮询/中断检测 U 盘插入（CMD_DISK_CONNECT）
3. 打开/创建 U 盘根目录 LOG.CSV（CMD_FILE_OPEN，追加模式）
4. 读取 W25Q16 记录 → 分块写入 U 盘（CMD_BYTE_WRITE）
5. 关闭文件（CMD_FILE_CLOSE）→ 蜂鸣器/LED 提示 → 拔出 U 盘
6. 可选：导出成功后清空 W25Q16，继续新一轮记录
```

### 3.2 关键实现点

1. **SPI1 分时**：操作 W25Q16 与 CH376 不能同时，用片选互斥（软件保证，天然串行）。
2. **导出模式**：导出时暂停实时记录或继续记录均可（U 盘写入很快，建议继续记录、分时搬运）。
3. **U 盘要求**：FAT16/FAT32 格式（CH376 内置支持），建议品牌 U 盘（杂牌兼容性差）。
4. **拔出时机**：必须等"导出完成提示"后再拔，防止文件损坏。
5. **容量规划**：2MB 记录数据一次导出约 1 分钟以内；U 盘容量不受限。

## 5. 注意事项清单

| # | 事项 | 后果 |
|---|------|------|
| 1 | U7 VCC 必须接 **VOUT5**（5V），不能接 3V3 | CH376 不工作/损坏 |
| 2 | SPI 网络名（SPI_SCK/MOSI/MISO）必须与 Flash 模块**完全一致** | 网络断裂 |
| 3 | CH_CS（PB12）与 SPI_CS（PA4）是**两个不同片选**，勿混淆 | 器件冲突 |
| 4 | X2 必须 **12MHz**（CH376 专用），不是系统 8MHz | CH376 时序错误 |
| 5 | C20 470uF 不能省 | U 盘插入浪涌可能导致复位 |
| 6 | 软件：导出完成提示后再拔 U 盘 | U 盘文件损坏 |
| 7 | 软件：SPI1 分时，片选互斥 | Flash/U 盘数据错乱 |

STM32 模拟 U 盘（USB MSC + FatFs，W25Q16 做 FAT16 磁盘），插电脑导出。硬件仅 Type-C + 1.5k D+ 上拉 + 5.1k×2 CC 下拉。成本低但必须带电脑，且 F103 USB 为 Device 模式天然支持。若未来需要"插电脑导出"形态可参考此方案。
