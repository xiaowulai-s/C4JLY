> 配套文件：`C4F7N_HMI_视觉稿_1024x600.html`（视觉参考，浏览器打开可交互演示）  
> 本清单目标：**让你在淘晶驰 USART HMI 编辑器里照抄搭建，无需设计**。

## 1. 新建工程（一次性）

1. 打开 **USART HMI**（淘晶驰官方上位机，下载：wiki.tjc1688.com）。
2. 文件 → 新建工程 → 选择 **7.0寸 1024×600** 对应型号（X5 平台，具体型号以你购买的屏幕为准，例如 X5-070… 系列）。
3. 工程设置（工程 → 设置）：
   - 分辨率：**1024 × 600**
   - 波特率：**115200**（与 STM32 USART1 一致）
   - 默认背景色：`#0B1526`（深蓝黑，RGB565 = 2212）
   - 方向：横屏（Landscape）

## 2. 页面与字库准备

### 2.1 新建 4 个页面

工具栏"页面"面板 → 新建页面，共 4 个：

| 页面    | 名称建议 | 用途      |
| ----- | ---- | ------- |
| page0 | 主页   | 浓度大字显示  |
| page1 | 设置   | 阈值 / 标定 |
| page2 | 历史曲线 | 波形 + 统计 |
| page3 | 关于   | 设备信息    |

### 2.2 添加中文字库（⚠️ 必须，否则中文乱码/不显示）

工程 → 字库 → 添加 **GB2312 全字库**（黑体或宋体），建议添加以下字号：

| 字号          | 用途                  |
| ----------- | ------------------- |
| 16          | 状态芯片 / 徽章 / 说明文字    |
| 24          | 标题 / 状态行 / 按钮文字     |
| 32          | 峰值数字 / 阈值数字         |
| **48 或 64** | 主页浓度大数字（选你工程可用的最大号） |

> 文本/数字/按钮控件的 `font` 属性必须选**带中文的那个字库**，否则中文显示为方块。

### 4.3 设置页脚本

**高报 `+`（`p1_hi_plus` rel）**：

```
p1_hi_val.val=p1_hi_val.val+50
if(p1_hi_val.val>1000)
  p1_hi_val.val=1000
endif
print "THR:HI:"
print p1_hi_val.val
```

**高报 `−`（`p1_hi_minus` rel）**：同上，`+50` 改 `-50`，上限 1000 改下限 100。  
**低报 `+` / `−`**：同结构，步进 10，范围 10~1000，指令 `THR:LO:`。

> ⚠️ `print p1_hi_val.val` 会把数字转文本发到串口；若你的固件版本不支持 print 变量，可改为只发 `print "THR:HI:CHANGED"`，由 MCU 主动回读 `p1_hi_val.val`。

**单位切换（`p1_unit_btn` rel）**：

```
if(p1_unit_btn.txt=="ppm")
  p1_unit_btn.txt="g/年"
else
  p1_unit_btn.txt="ppm"
endif
print "UNIT:TOGGLE"
```

**蜂鸣器开关（`p1_buz_btn` rel）**：

```
if(p1_buz_btn.txt=="开")
  p1_buz_btn.txt="关"
  p1_buz_btn.bco=2212
else
  p1_buz_btn.txt="开"
  p1_buz_btn.bco=9771
endif
print "BUZ:TOGGLE"
```

**背光滑块（`p1_dim` 的 `up` 拖动结束事件）**：

```
dim=p1_dim.val
p1_dim_val.txt=p1_dim.val
p1_dim_val.txt=p1_dim_val.txt+"%"
```

**零点标定（`p1_cal0_btn` rel）**：

```
p1_cal0_btn.txt="执行中…"
print "CAL:ZERO"
```

**量程标定（`p1_cal1_btn` rel）**：

```
p1_cal1_btn.txt="执行中…"
print "CAL:SPAN"
```

**恢复出厂（`p1_fac_btn` rel）**：

```
print "CAL:FACTORY"
```

## 7. 串口通讯协议（STM32 ↔ 屏幕）

> 波特率 **115200**，数据帧以 **0xFF 0xFF 0xFF** 结尾（Nextion 兼容协议）。STM32 侧 USART1（PA9/PA10）。

### 7.1 MCU → 屏幕 指令表（更新显示）

| 功能     | 指令                                   | 示例 / 说明                           |
| ------ | ------------------------------------ | --------------------------------- |
| 切换页面   | `page N`                             | `page 0` 主页                       |
| 设置浓度   | `p0_conc.val=xx`                     | `p0_conc.val=42` → 显示 0.42（vvs=2） |
| 设置峰值   | `p0_peak.val=xx`                     | `p0_peak.val=123` → 显示 1.23       |
| 均值徽章   | `p0_badge_avg.txt="均值 0.42"`         | 中文文本需 GB2312                      |
| 状态行    | `p0_t90.txt="4.2 s"` 等               | 同理更新 p0_flow / p0_temp / p0_thr   |
| 报警条颜色  | `p0_strip.pco=9771`                  | 9771 绿 / 62689 橙 / 59944 红        |
| 波形喂点   | `add 0,数值`                           | 数值 0~255，0→0ppm，255→1000ppm       |
| 波形清屏   | `cls 0`                              | 切换时间段时                            |
| 亮度     | `dim=70`                             | 0~100                             |
| 蜂鸣     | `beep 1`                             | 1 响；配合报警                          |
| 阈值同步   | `p1_hi_val.val=500` 等                | 开机/恢复出厂后回读                        |
| 统计更新   | `p2_max.txt="248.5"` 等               | p2_max/avg/min/dur/cnt            |
| 标定按钮复位 | `p1_cal0_btn.txt="执行"`               | 标定完成后由 MCU 复位按钮文字                 |
| 探头状态   | `p3_probe_st.txt="MST-N7M 探头 · 已连接"` | 断连时改红色并更新文字                       |

### 7.2 屏幕 → MCU（按钮上报，无结束符约定，MCU 按关键字匹配）

| 关键字                                     | 含义                             |
| --------------------------------------- | ------------------------------ |
| `PEAK:RESET`                            | 用户点重置峰值                        |
| `THR:HI:`（后接数字）                         | 高报阈值变更                         |
| `THR:LO:`（后接数字）                         | 低报阈值变更                         |
| `UNIT:TOGGLE`                           | 单位切换请求（ppm ↔ g/年换算由 MCU 决定显示值） |
| `BUZ:TOGGLE`                            | 蜂鸣器开关请求                        |
| `CAL:ZERO` / `CAL:SPAN` / `CAL:FACTORY` | 零点 / 量程 / 恢复出厂                 |
| `RANGE:10M` / `RANGE:1H` / `RANGE:24H`  | 曲线时间范围切换                       |
| `EXPORT`                                | 导出 CSV（USB CDC）                |

> MCU 收到标定请求后应进入对应流程，完成后回发指令复位按钮文字并保存参数至 Flash / 下发 W25Q16 记录。

## 8. 编译与烧录

1. **编译**：USART HMI → 文件 → 编译（或工具栏"编译"），生成 `.tft` 文件。
2. **TF 卡烧录（推荐）**：
   - 将 `.tft` 文件放入 TF 卡根目录（文件名保持编译输出名，如 `X5-070W_V1.0.tft`，以你屏幕型号要求为准）；
   - 屏幕断电 → 插卡 → 上电 → 自动升级（屏幕提示进度）→ 完成拔卡。
3. **串口下载**：用 USB-TTL 连接屏幕调试口，USART HMI 的"下载"功能直接烧录（波特率自动）。
4. 烧录后先发 `page 0` 和 `p0_conc.val=42` 验证通信。

## 10. 常见坑（对照检查）

| #  | 坑                 | 对策                                         |
| -- | ----------------- | ------------------------------------------ |
| 1  | 中文显示为方块/乱码        | 必须添加 **GB2312 中文字库**，且控件 font 选该字库         |
| 2  | 控件 ID 混乱          | 控件 ID 按**创建顺序**分配；严格按本清单顺序创建，中途不要插建        |
| 3  | 浓度显示没有小数          | 数字控件设 **vvs=2**（val=42 显示 0.42）            |
| 4  | 串口指令无效            | 指令必须以 **0xFF 0xFF 0xFF** 结尾，且波特率 115200 一致 |
| 5  | 按钮误触发             | 导航/标定用 **rel（释放）** 事件，不用 prs（按下）           |
| 6  | 波形不显示             | `add` 值必须 0~255；bco 与背景不同色                 |
| 7  | 画面闪烁/慢            | 中文文本改动尽量少发；曲线用 `add` 增量喂点而非整帧刷新            |
| 8  | objname 报重复       | 对象名**全局唯一**，跨页引用同名会冲突                      |
| 9  | 恢复出厂无确认           | 本版直接执行；后续可加弹窗页（page4）做二次确认                 |
| 10 | X5 无某属性（如 radius） | 忽略该属性即可，不影响功能                              |
