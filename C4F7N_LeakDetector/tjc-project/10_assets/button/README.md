# 10_assets/button

当前版本按钮均为「控件直绘」（bco/pco/radius），不加载按钮图片，刷新快、省 Flash。

| 控件 | 类型 | 尺寸 | 说明 |
| -- | -- | -- | -- |
| 底部导航 | button | 256×52 | 4 等分，当前页 bco=3222 高亮 |
| 阈值步进 +/- | button | 44×44 | 7寸屏约 6.6mm，偏小但可用；如需加大建议 48×48 |
| 标定执行 | button | 110×44 | 右面板内 |
| 恢复出厂 | button | 110×44 | bco=59944 红色警示 |

如需贴图按钮（如金属质感），规格：

| 项 | 要求 |
| -- | -- |
| 格式 | PNG，≤ 24bit |
| 尺寸 | 与控件一致（如 256×52） |
| 状态 | 至少 2 态：正常 / 按下 |
| 命名 | `btn_nav_home_normal.png` / `btn_nav_home_press.png` |

> 默认不推荐：按钮图片会增加资源体积与切图工作量，工业 HMI 以清晰色块为佳。
