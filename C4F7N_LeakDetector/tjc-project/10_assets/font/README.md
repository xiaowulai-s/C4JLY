# 10_assets/font

⚠️ 中文字库是**必需**的：不加 GB2312 中文字库，所有中文显示为方块/乱码。

## 字库清单（在 USART HMI 工程 → 字库中添加）

| 字库 | 字号 | 用途 | Flash 占用 |
| -- | -- | -- | -- |
| GB2312 全字库（黑体/宋体） | 16 | 状态芯片/说明/正文 | 中 |
| GB2312 全字库 | 24 | 标题/按钮/状态行 | 中 |
| GB2312 全字库 | 32 | 峰值/阈值数字 | 中 |
| **ASCII/数字专用字库** | 48（或 64） | 主页浓度大数字 | **小**（强烈建议） |

## 字体策略要点

1. **主页大数字**：`p0_conc` 只显示数字和小数点，用 **ASCII 数字字库 48** 即可，不要用 48 号中文全字库（占 Flash 大）。
2. 若 X5 编辑器不支持数字专用字库，可用 48 号 ASCII 字库代替（GB2312 中文全字库 48 号作为备选，会明显增加编译体积）。
3. 控件 `font` 属性必须选对字库 ID：
   - 含中文的控件 → GB2312 字库（16/24/32）
   - `p0_conc` 数字大字 → 数字字库 48
4. 本工程不使用自绘字体文件（.ttf/.fon 由 USART HMI 内置转换为 .zi），故 assets/font 目录留空；如需第三方字体，将 .ttf 放入此目录并在 USART HMI 中引用。

## 字符集风险（验证报告 §5 详列）

- `↺`（U+21BA）不在 GB2312 → 已从「重置峰值」按钮文字中去除
- `●`、`℃`、`·`、`×`、`≤`、`—` 均在 GB2312 符号区，但建议真机确认显示
