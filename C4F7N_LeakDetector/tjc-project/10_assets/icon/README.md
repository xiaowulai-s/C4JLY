# 10_assets/icon

当前版本 UI 全部使用「文字 + 色块」实现，无需图标图片（省 Flash、零分辨率风险）。

可选优化（后续如需）：状态芯片图标（探头/泵/电量）

| 图标 | 建议尺寸 | 格式 | 说明 |
| -- | -- | -- | -- |
| 探头状态圆点 | 16×16 | PNG 单色 | 绿/红两态 |
| 泵状态圆点 | 16×16 | PNG 单色 | 绿/灰两态 |
| 电量图标 | 24×16 | PNG 单色 | 5 档 |
| 返回箭头 | 32×32 | PNG 单色 | 如增加弹窗页 |

设计要求（低分辨率 LCD 适配）：

- 单色或双色，高对比度
- 线条宽度 ≥ 2px，避免细小笔画
- 禁止复杂渐变、半透明阴影
- 命名：`ic_probe_green.png`、`ic_pump_off.png`、`ic_bat_3.png` 等
