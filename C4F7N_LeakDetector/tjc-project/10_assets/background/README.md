# 10_assets/background

本工程**不使用背景图片**，全屏纯色背景：

- 主背景色：`#0B1526`（RGB565 = 2212）
- 面板色：`#12233C`（RGB565 = 4359）

在 USART HMI 工程设置中把默认背景色设为 2212 即可，无需任何图片资源，最大化节省 Flash。

如需品牌化背景图（不推荐，占用 Flash 且影响刷新），规格如下：

| 项 | 要求 |
| -- | -- |
| 格式 | PNG（RGB565 导出更省） |
| 尺寸 | 1024×600 整屏 |
| 大小 | ≤ 200 KB（16MB Flash 下建议 ≤ 100KB） |
| 内容 | 深蓝黑底、无文字（文字一律用控件，避免放大模糊） |
