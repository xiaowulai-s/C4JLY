## 如何编译得到 .tft（在装有 USART HMI 的电脑上）

1. **下载工具**：淘晶驰官网 wiki.tjc1688.com → 下载「USART HMI」上位机（X5 平台对应版本）。
2. **新建工程**：文件 → 新建 → 选择 **7.0寸 1024×600（X5 平台）** 型号。
3. **工程设置**（工程 → 设置）：
   - 分辨率 1024×600 ｜ 波特率 115200 ｜ 背景色 `#0B1526`（RGB565 2212）｜ 方向横屏
4. **添加字库**（工程 → 字库）：
   - GB2312 全字库 16 / 24 / 32
   - ASCII 数字字库 48（主页浓度大数字用）
5. **搭建页面**：按 `09_pages/p0~p3.json` 的坐标/尺寸/属性逐控件创建（推荐按 id 顺序创建，保证控件 ID 一致）。
6. **粘贴脚本**：将 `11_scripts/p0_main.hmi` ~ `p3_about.hmi` 中对应事件的脚本粘贴到控件事件框（global.hmi 为初始化约定说明）。
7. **编译**：文件 → 编译（或工具栏编译），输出 `xxx.tft`。
8. **烧录**（二选一）：
   - TF 卡：`.tft` 放 TF 卡根目录 → 断电插卡 → 上电自动升级 → 完成拔卡
   - 串口：USART HMI 的「下载」功能直接烧录
9. **联调验证**：发 `page 0`、`p0_conc.val=42` 验证通信；`add 0,128` 验证波形。

## 建议

编译完成后，把生成的 `.tft` 与本校验摘要一并归档到本目录，并回填 `validation_summary.json` 的 `build_status` 为 `COMPILED`。
