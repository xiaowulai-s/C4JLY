# C4F7N 检漏仪 · 淘晶驰串口屏下载/烧录指南

> 适用：TJC X5 平台 · 7 寸 1024×600 横屏 · 工程位于本目录 `tjc-project/`
> 状态：本机未安装 USART HMI 官方工具链，`.tft` 需在官方上位机中编译生成（本指南给出全部操作步骤）

---

## 0. 完整流程总览

```
tjc-project/  (JSON + 脚本 + 资源清单)
      │  ① USART HMI 上位机中重建工程（约 30~60 分钟）
      ▼
   官方工程 (.HMI) ── ② 编译 ──▶ xxx.tft
                                    │  ③ 烧录（三选一）
                                    ▼
                            淘晶驰串口屏 (X5-070)
```

**关键点**：AI 生成的 `09_pages/*.json` 是「中间工程」，不是官方 `.HMI` 文件；`.tft` 只能由官方 USART HMI 工具链编译产出，本工程没有伪造 `.tft`。

---

## 1. 前置条件

| 项目 | 要求 |
|---|---|
| 上位机 | 淘晶驰 **USART HMI**（官网 www.tjc1688.com → 下载中心 → X5 系列对应版本） |
| 电脑驱动 | 如用 USB 串口下载，需装 USB-TTL 模块驱动（CH340 / CP210x / FT232） |
| SD/TF 卡 | FAT32 格式、≤32GB（SD 卡烧录用） |
| 屏幕 | X5-070 7 寸 1024×600 横屏，确认有 SD 卡槽 |
| 串口接线 | USB-TTL 模块 + 杜邦线（串口烧录用） |

> ⚠️ 烧录前**断开屏幕与 STM32 主控的 UART 连线**（或确认 STM32 不上电），避免两条数据通路抢占用串口。

## 2. 第一步：在 USART HMI 中重建工程

### 2.1 新建工程
1. 打开 USART HMI → 「新建工程」
2. 选择型号：**X5-070（1024×600）**，方向：**横屏**（LANDSCAPE）
3. 系统设置确认：串口 **115200 / 8N1**、背景色按 `01_project_spec.md` 深色主题

### 2.2 添加字体（与 10_assets/font/README.md 一致）
| 字体 | 用途 | 覆盖字符 |
|---|---|---|
| GB2312 16pt | 标签、提示文字 | 中文 + ASCII |
| GB2312 24pt | 页标题、按钮文字 | 中文 + ASCII |
| GB2312 32pt | 状态栏大字、报警文字 | 中文 + ASCII |
| ASCII 数字 48pt | 主页浓度大数字（省 Flash） | 0-9 . - |

### 2.3 建 4 个页面
| 页面 ID | 名称 | 来源文件 |
|---|---|---|
| 0 | 主页 | `09_pages/p0_main.json` |
| 1 | 设置 | `09_pages/p1_settings.json` |
| 2 | 历史曲线 | `09_pages/p2_curve.json` |
| 3 | 关于 | `09_pages/p3_about.json` |

### 2.4 逐页添加控件
打开每页的 `09_pages/pX_*.json`，按 `components[]` 逐条添加：

- **类型映射**：`text`→文本控件、`number`→数据控件、`button`→按钮控件、`progress`→进度条/滑动条、`curve`→曲线控件、`image`→图片控件
- **属性照抄**：`x / y / w / h / font / size / color / text` 等字段逐一填写
- **事件脚本**：控件事件粘贴 `11_scripts/pX_*.hmi` 中对应代码段
- 主页浓度大数字用 48pt 数字字体；底部导航 4 个按钮统一接「页面跳转」事件

### 2.5 编译
1. 菜单「编译」或快捷键 Ctrl+B
2. 确认输出路径，生成 **xxx.tft**
3. 记录 .tft 文件位置，进入第 3 步烧录

---

## 3. 第二步：烧录（三选一）

### 方式 A：SD/TF 卡烧录（最稳，推荐量产/现场用）

| 步骤 | 操作 |
|---|---|
| 1 | 将 `.tft` 重命名为 **`TJC_SETUP.tft`** |
| 2 | 复制到 **FAT32 格式 SD 卡根目录**（不要放子文件夹） |
| 3 | **断电**，SD 卡插入屏幕卡槽 |
| 4 | 上电，屏幕自动进入烧录（显示进度），**过程中严禁断电** |
| 5 | 烧录完成 → 断电 → 拔出 SD 卡 → 重新上电进入运行画面 |

> 文件名规则以你手中屏幕型号说明为准（淘晶驰多数型号为 `TJC_SETUP.tft`）。

### 方式 B：USB-TTL 串口烧录（开发调试方便）

| 步骤 | 操作 |
|---|---|
| 1 | USB-TTL 模块接线：**屏幕 TX → 模块 RX、屏幕 RX → 模块 TX、GND → GND** |
| 2 | 模块插电脑，设备管理器确认 COM 口号 |
| 3 | USART HMI 上位机 → 「设置」选对应 COM 口、下载波特率（默认即可） |
| 4 | 点「下载」按钮，屏幕进入下载模式，自动完成烧录 |
| 5 | 完成后断开模块，恢复与 STM32 的接线 |

### 方式 C：经 STM32 主控 UART 下载（量产批量用）

- 需要主控固件支持「透传/下载转发」功能，将 .tft 字节流通过 UART 发给屏幕
- 波特率与协议按屏幕下载规范，一般由产测工具实现
- 当前 C4F7N 固件如未实现该功能，优先用方式 A/B

## 4. 烧录后自检清单

| 检查项 | 预期 |
|---|---|
| 上电画面 | 主页深色背景 #0B1526，状态栏显示时间/电量 |
| 浓度大字 | 显示 0.0 ppm，绿色 |
| 底部导航 | 4 个按钮可切换 4 页 |
| 曲线页 | 无数据时网格正常显示 |
| 串口 | STM32 连接后 115200 收到浓度刷新（250ms） |

---

## 5. 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 上电黑屏/白屏 | 烧录失败或 .tft 与型号不匹配 → 检查文件名、SD 卡 FAT32、重新烧录 |
| 下载进度条卡住 | 烧录中断电或 SD 卡异常 → 重新格式化 FAT32 再试 |
| 中文乱码 | 字库未添加 GB2312 → 回 2.2 补字库 |
| 数字显示异常 | 数字控件未绑定对应字体/变量 → 检查 09_pages JSON 的 font 与变量映射 |
| 串口通信无响应 | 波特率不是 115200 8N1 / STM32 未发送 / TX RX 接反 |
| 触摸无反应 | 按钮控件未开「触摸使能」/ 未添加 Touch 事件 |
| 页面跳转无效 | 按钮事件里 `page` 指令目标页号写错 → 对照 PAGE_MAP |
