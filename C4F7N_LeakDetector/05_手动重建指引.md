# C₄F₇N 检漏仪 — 立创 EDA 手动重建指引

> 配合《04_连接清单.md》使用：本文件讲**怎么操作**，连接清单讲**怎么接线**。
> 目标：在立创 EDA 标准版新工程中，用立创库元件按模块重画主机主板原理图。

---

## 一、准备工作

1. 打开 **lceda.cn**（标准版）→ 登录 → 新建工程，命名 `C4F7N_LeakDetector` → 新建原理图
2. 打开《04_连接清单.md》对照接线（建议打印或分屏）
3. 立创标准版常用快捷键：

| 操作 | 快捷键 |
|------|--------|
| 放置导线 | `P`（或菜单：放置→导线） |
| 网络标签 | `N`（放置→网络标签） |
| 放置电源/地 | `G`（放置→电源/端口） |
| 元件库面板 | `F2` 或右侧面板 |
| 保存 | `Ctrl+S`（云存储自动保存） |
| 检查(ERC) | 设计→检查→ERC |

## 二、重建顺序（12 步，按模块推进）

> 原则：**每完成一个模块立即连线并放网络标签**，最后统一接 5V/3V3/GND 总线。不要全部放完再连线（容易乱）。

### 第 1 步：电源-充电模块（4 器件）

放置：`J1 Type-C 母座`、`F1 保险丝 0805 500mA`、`U1 TP4056`、`BT1 18650 电池座`

连线（见清单模块 1）：
- **VBUS**：J1.1 → F1.1
- **VBUS_F**：F1.2 → U1.VCC(1)
- **BAT**：U1.BAT(7) → BT1.+
- **CHRG**：U1.CHRG(6) → D1 阴极（充电红灯）
- **GND**：J1.5/7 → U1.GND → BT1.-

> ⚠️ 修正点 1：U1 的 CE(2) 接 **VBUS_F**（不是 5V），否则电池耗尽无法充电。
> PROG(3) 接 R1 1.2k → GND（设定充电电流 ~1A）。

### 第 2 步：电源-升压模块（8 器件）

放置：`U2 MT3608`、`L1 10uH`、`D2 SS34`、`R2 100k`、`R3 20k`、`C1 10uF`、`C2 22uF`

连线：
- **BAT** → U2.VIN(5)，BAT → L1 → U2.SW(1)
- **SW**：U2.SW(1) → D2 阳极
- **VOUT5**：D2 阴极 → C2+ → R2 → U2.FB(3)，R3(20k) 从 FB → GND
- > ⚠️ 修正点 2：U2.EN(4) 接 **BAT**（不是 5V），否则升压无法自启动

### 第 3 步：电源-LDO 模块（3 器件）

放置：`U3 AMS1117-3.3`、`C3 10uF`、`C4 10uF`

连线：**VOUT5** → U3.VIN(3)，U3.VOUT(2) → **3V3**，C3/C4 分别滤波 5V/3V3 → GND

### 第 4 步：电源-去耦/CC 电阻（8 器件）

放置：`C5/C6/C9/C10/C13 100nF`、`R12/R13 5.1k`

连线：C5/C6/C9/C10 → **3V3** 与 GND；C13 → **5V** 与 GND；R12: **CC1**→GND；R13: **CC2**→GND

### 第 5 步：MCU 最小系统（U4 STM32F103C8T6）

放置：`U4 STM32F103C8T6`（立创搜型号直接出 LQFP-48 符号）

连线（核心，逐脚对照清单）：
- 电源脚：VDD/VDDA/VBAT → **3V3**，VSS → **GND**
- NRST(5) → R5 10k 上拉 3V3 + SW1 复位按键 → GND
- BOOT0(6) → R6 10k 下拉 GND
- PA13/PA14 → SWDIO/SWCLK（接调试口）

### 第 6 步：MCU 时钟/调试（5 器件）

放置：`Y1 8MHz 晶振`、`R4 1M`、`C7/C8 20pF`、`J6 排针 1x4`

连线：PD0(OSC_IN) ↔ Y1.X1，PD1(OSC_OUT) ↔ Y1.X2；C7: OSC_IN→GND，C8: OSC_OUT→GND；R4(1M) 并联在晶振两端
J6：1=3V3，2=SWDIO，3=SWCLK，4=GND

### 第 7 步：电池采样（3 器件）

放置：`R22/R23 100k`、`C14 100nF`

连线：**BAT** → R22 → **VBAT_SENSE** → R23 → GND；C14 滤波 VBAT_SENSE → GND

### 第 8 步：串口屏接口（J2）

放置：`J2 排针 1x4`，接 **5V / GND / LCD_TX / LCD_RX**（LCD_TX 接 MCU PA9，LCD_RX 接 PA10）

### 第 9 步：RS485 手柄接口（3 器件）

放置：`U5 MAX3485`、`R9 120Ω`、`J3 GX12 航空插头(4芯)`

连线：RO→RS485_RX(PA3)，DI→RS485_TX(PA2)，/RE(2)与DE(3)合并接 **RS485_DE**；A(6)/B(7) 之间 R9 120Ω；A/B → J3.3/4；J3.1=5V，J3.2=GND

### 第 10 步：Flash 存储（U6）

放置：`U6 W25Q16`，连线：/CS→SPI_CS(PA4)，DO→SPI_MISO(PA6)，DI→SPI_MOSI(PA7)，CLK→SPI_SCK(PA5)，/WP(3)/HOLD(7)/VCC(8)→3V3

### 第 11 步：泵驱动（4 器件）

放置：`Q1 SI2302`、`R15 100k`、`D3 1N5819`、`J4 XH2.54 2P`

连线：PA0 → Q1.G（R15 下拉 GND）；Q1.D → **PUMP_N**；Q1.S → GND；J4：1=VOUT5，2=PUMP_N；D3: A→PUMP_N，K→VOUT5（续流）

### 第 12 步：蜂鸣器/LED/按键（10 器件）

- 蜂鸣器：`BZ1` 有源蜂鸣器 3V3 ↔ Q2(MMBT2222) 驱动；PA1 → R16 1k → Q2.B；Q2.E→GND，Q2.C→BZ1-
- LED：`LED1 红`(PA15)、`LED2 绿`(PB0)，各串 R17/R18 330Ω
- 按键：`SW2/SW3/SW4` 接 KEY1(PB3)/KEY2(PB4)/KEY3(PB5) → GND

### 最后：电源总线检查

确认全图 **5V / 3V3 / GND** 三根总线通过网络标签正确连通所有器件（对照清单第 49 个网络逐个核对）。

## 三、完成后的检查清单

| 检查项 | 方法 |
|--------|------|
| 电气规则检查 ERC | 设计→检查→ERC，**0 错误** |
| 网络连通性 | 点任意网络标签 → 高亮整条网络 |
| 位号完整性 | 无重复位号（R1-R23、C1-C14、U1-U6…） |
| 修正点 | U1.CE→VBUS_F ✓、U2.EN→BAT ✓ |
| 封装 | 每个器件已选立创封装（或留待 PCB 阶段统一指定） |

---

## 四、预计工作量与分工

- 全部按清单重建：约 **3-4 小时**（器件放置 1h + 连线 2h + 检查 0.5h）
- 可以**分 2 次完成**：先做电源区（1-4 步）+ MCU 区（5-7 步），休息后再做接口/驱动区（8-12 步）
