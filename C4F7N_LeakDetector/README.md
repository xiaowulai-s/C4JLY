# C4F7N 便携式检漏仪 · 项目总览

> 器件：C4F7N 全氟异丁腈 NDIR 传感模组（GC5G1）
> 主控：STM32F103RCT6（LQFP64，256KB Flash / 48KB RAM）
> 屏幕：TJC 7寸 USART HMI 1024×600（`C4F7N_HMI_v18.HMI`）
>

---

**状态：软件全部收敛并编译通过，处于硬件就绪后的真机联调门槛前。** 屏幕程序化生成与 MCU 三阶段固件进度均为主干，剩余两项为曲线页数据实现与真机双向联调，均不阻塞当前收尾。

### 关键实现要点

- 屏幕→MCU：`printh 单字节命令码`（0x01~0x24），规避脚本行 ≤15B 硬约束。
- MCU→屏幕：Nextion 指令 + `0xFF 0xFF 0xFF` 帧尾。
- 传感器量程按用户设定映射 0~1000ppm（忽略器件 3000ppm 全量程标称）。
- 参数（标定系数、高/低阈值、蜂鸣器、单位）存 W25Q16 0 扇区，带 CRC，上电 `param_init` 加载。
