## 1. 项目概述

开发一台便携式 **C₄F₇N（全氟异丁腈，3M Novec 4710）检漏仪**，用于电力行业 GIS、高压断路器、环网柜等新型环保绝缘气体设备的现场泄漏检测与定位。

- **背景**：C₄F₇N 作为 SF₆ 环保替代品正规模化应用（绝缘强度为 SF₆ 两倍、GWP 低），泄漏会影响设备绝缘性能并带来环保风险，需现场快速检测。
- **竞品参考**：DILO LEAKSPY C4（0-1000ppm，NDIR，传感器延长杆式）、JHLK200-C4（0-1000ppm，0.01ppm 显示）、LF-300-C4（高频电离，0.01-100ppm）。
- **本机差异化**：传感器置于可换探头手柄（响应快）、18650 可换电池（现场续航）、4.3 寸触摸屏、板载 Flash 曲线记录 + USB 导出 CSV。

## 2. 需求指标

| 项目 | 指标 | 说明 |
|------|------|------|
| 检测气体 | C₄F₇N（全氟异丁腈 / Novec 4710） | SF₆ 环保替代气 |
| 量程 | 0 ~ 1000 ppm | DILO 同量程 |
| 显示分辨率 | 0.01 ppm | ⚠️ 实为显示步进；检出限物理上 0.3~1 ppm |
| 响应时间 | T90 ≤ 5 s（目标） | 需样件台架验证确认 |
| 检测原理 | NDIR 双波长红外 | 7.9μm 特征吸收 + 3.3μm 参考通道 |
| 使用环境 | -20 ~ +60 ℃ | 变电站现场 |

> **指标口径澄清**："0.01ppm 灵敏度"为显示分辨率（JHLK200-C4 同口径），真实检出限由 NDIR 光学结构决定，行业水平 0.3~1 ppm，验收时按检出限而非显示步进考核。

## 3. 系统架构（分布式）

**核心决策**：传感器模组放在探头手柄内，微型泵留在主机。决定响应时间的只有传感器之前的气路，泵在主机抽吸不影响读数，手柄因此轻量（<150g）且无振动。

```
[可换探头套装] → 手柄{MST-N7M + 接口板(RS485)} → 复合管线 → 主机{泵→排气 / STM32 / 串口屏 / 电池 / 报警}
```

| 部件 | 组成 |
|------|------|
| 🔍 探头手柄（可换） | 可换探头嘴（鹅颈/直杆/延长杆）、MST-N7M NDIR 模组（63g）、接口板（TTL→RS485）、手温隔离层 |
| 复合管线 | 气路软管（测量后传输）+ 4 芯电缆（5V·GND·A·B） |
| 🎛 主机（手持机） | 微型隔膜泵（抽吸·排气）、STM32F103C8T6、4.3寸电容触摸串口屏、18650×2 电池、声光报警/蜂鸣器/按键 |

**关键设计原则**：

1. **μV 级模拟信号不出手柄**——热电堆输出微伏级，必须手柄内数字化后走 RS485 差分传输。
2. **泵留主机**——气体在气室被测量后才进入软管，软管长度不影响响应。
3. **探头可快速更换**——GX12 航空插头（4 芯：5V/GND/A/B）。

**响应时间预算**（T90 ≈ 3-5 s）：

```
探头嘴→气室 ~0.2s → 气室换气 0.5-1s → NDIR 电路 2-3s → 数字滤波 0.5s
```

## 4. 硬件选型（决策记录）

| 模块 | 选型 | 关键参数 / 备选 |
|------|------|----------------|
| 气体传感器 | **MST-N7M**（宁夏麦芽） | NDIR，0-1000ppm，1ppm 分辨率，TTL UART，3.0-5.5V，63g。备选：LARK-1QM（T90 10s，±2ppm）/ GC5G1（工业接口全但响应慢） |
| 微型泵 | **5V 无刷隔膜泵** | 空载 ≥1 L/min，真空度 ≥-40kPa，噪音 <50dB，寿命数千小时 |
| 主控 MCU | **STM32F103C8T6** | LQFP-48，72MHz，USB FS 原生 |
| 人机界面 | **4.3寸 800×480 电容触摸串口屏** | 淘晶驰 X3/X5 或迪文；串口指令控制，可视化拖拽开发 |
| 存储 | **W25Q16**（SPI Flash） | 16Mbit，浓度曲线记录（数月） |
| RS485 接口 | **MAX3485** | 3.3V 收发器，半双工，A/B + 120Ω 终端 |
| USB | **Type-C**（与充电共用） | STM32 原生 CDC，CSV 导出 |
| 充电 | **TP4056** | 1A 线性充电，PROG 1.2k 设定 |
| 升压 | **MT3608** | 3.7V→5V 升压，10uH 电感 + SS34 |
| LDO | **AMS1117-3.3** | 5V→3.3V，1A |
| 电池 | **18650 ×2 并联** | 5000mAh，可现场更换，Type-C 充电 |
| 驱动 | SI2302（泵 N-MOS）/ MMBT2222（蜂鸣器） | 泵低边开关 + 1N5819 续流 |
| 探头连接 | **GX12 航空插头 4 芯** | 5V / GND / RS485_A / RS485_B |

## 5. 原理图设计（主机主板）

56 个器件，4 大模块，48 个网络。已产出 KiCad 工程（v2）与立创 EDA 标准版 JSON 原生工程（`C4F7N_MainBoard.json`），并制定手动重建指引。

| 模块 | 包含器件 | 关键网络 |
|------|---------|---------|
| 电源区 | J1 Type-C、F1、U1 TP4056、BT1、U2 MT3608、L1、D2、U3 AMS1117、R1-R3/R12/R13、C1-C6/C9/C10/C13 | VBUS / VBUS_F / BAT / VOUT5 / 5V / 3V3 / GND / CC1 / CC2 |
| MCU 区 | U4 STM32F103C8T6、Y1 8MHz、R4-R6、SW1、J6 SWD、R22/R23、C7/C8/C11/C12/C14 | RST / BOOT0 / SWDIO / SWCLK / OSC_IN/OUT / VBAT_SENSE |
| 接口区 | J2 串口屏、U5 MAX3485、R9、J3 GX12、U6 W25Q16 | LCD_TX/RX / RS485_* / SPI_* / USB_DP/DM |
| 驱动区 | Q1/Q2、R15-R18、D3、J4 泵、BZ1、LED1/2、SW2-SW4 | PUMP_CTRL / PUMP_N / BEEP / LED_* / KEY1-3 |

### STM32 引脚分配

| 功能 | 引脚 | 外设 |
|------|------|------|
| 串口屏 | PA9 / PA10 | USART1 TX/RX（115200 级） |
| RS485（手柄） | PA2 / PA3 / PA1 方向 | USART2 TX/RX + DE |
| SPI Flash | PA4 / PA5 / PA6 / PA7 | SPI1 CS/SCK/MISO/MOSI |
| USB | PA11 / PA12 | USB DM/DP（CDC 导出） |
| 泵控制 | PA0 | PWM 可调速 |
| 蜂鸣器 | PA1 | — |
| 报警 LED（红）/电源 LED（绿） | PA15 / PB0 | — |
| 电池电压采样 | PB1 | ADC（R22/R23 分压） |
| 按键 | PB3 / PB4 / PB5 | KEY1-3（内部上拉） |
| SWD | PA13 / PA14 | 调试口 |
| 晶振 | PD0 / PD1 | 8MHz HSE + 20pF×2 + 1M |

> **⚠ 设计修正点（基线内已生效，重建/改板时务必遵守）：**
> ① TP4056 的 CE(2) 接 **VBUS_F**（USB 输入），不可接 5V——否则电池耗尽时 5V 无法建立，充电功能失效。
> ② MT3608 的 EN(4) 接 **BAT**（电池），不可接 5V——否则升压输出未建立时 EN 为低，升压无法自启动。

## 6. 电源方案

```
Type-C 5V → TP4056 充电 1A → 18650×2 并联 3.7V → MT3608 升压 5V → AMS1117 → 3.3V
```

| 项目 | 方案 | 说明 |
|------|------|------|
| 电池 | 18650 ×2 并联（5000mAh） | **可现场更换**，续航 5-6h |
| 充电 | TP4056 + Type-C | 充电电流 ~1A（R_PROG=1.2k） |
| 升压 | MT3608 → 5V | 泵/传感器/串口屏供电（150mA 余量充足） |
| LDO | AMS1117 → 3.3V | MCU/RS485/Flash |
| 功耗预算 | 约 600mA @5V（峰值 ~900mA） | MST-N7M 150mA + 泵 350mA + 屏 300mA + MCU 80mA |

## 7. 软件功能

- **浓度实时显示**：0.01 ppm 步进，可切 ppm / g/年
- **声光报警**：阈值可设（蜂鸣器频率随浓度变化 + 红色 LED）
- **峰值保持**：锁定最大浓度位置（检漏定位核心功能）
- **数据记录**：W25Q16 Flash 记录浓度曲线（数月），USB CDC 导出 CSV
- **串口屏 UI**：主页（浓度大字）/ 设置（阈值·标定）/ 历史曲线 / 关于
- **标定**：零点 + 量程标定流程（串口屏引导）

无上位机、无蓝牙（保持简单可靠，按决策 v1.0）。

## 9. 关键风险与对策

| 风险 | 影响 | 对策 |
|------|------|------|
| 成品模组 T90 标称 <20s | 5s 指标不达标 | 高流量抽吸（>0.5L/min）+ 与厂商谈固件定制（提输出频率 4Hz、缩平均窗口）；样件台架实测 |
| 手温漂移 | 影响 0.01ppm 显示稳定 | 手柄隔热层 + 双通道参考补偿 + 板载温度传感 |
| 鹅颈探头气路损耗 | 流量下降拖慢响应 | 泵选型已留余量（空载 1L/min），实测复核 |
| C₄F₇N 标气采购难 | 绝对精度无法验证 | 先用 SF₆ 标气做相对 T90 验证，标气到位后补精度 |
| KiCad→立创导入兼容 | 原理图迁移受阻 | 已改走立创原生 JSON + 手动重建（指引已备） |

## 10. 样件验证计划（台架）

**前置条件**：MST-N7M ×2、5V 泵 ×1、4.3寸串口屏 ×1、标气（10/100/1000ppm）、USB-TTL、流量计。

| 步骤 | 内容 | 判定标准 |
|------|------|---------|
| 1 串口连通 | 上电读串口，确认协议/波特率/预热时间；索取协议手册 | 帧结构可解析 |
| 2 流量标定 | 0.3 / 0.5 / 1.0 L/min 三档实测 | 气路无泄漏 |
| 3 **T90 测试** | 空气↔标气阶跃，记录 T10→T90（三档流量 × 三浓度） | **T90 ≤ 6s**（留余量） |
| 4 手温漂移 | 手握 30min 记录漂移 | < 2 ppm |
| 5 重复性/零点 | 100ppm×5 次 CV；洁净空气 10min 零点 | CV < ±1.5%；零点 < ±1ppm |
| 6 功耗 | 稳态/峰值电流 | 修正续航估算 |

**结论触发**：通过 → 锁定 MST-N7M、按 0.5L/min 设计气路、开始 PCB 细化；不通过 → 厂商固件定制 → 复测；仍不达标 → 回退 LARK-1QM（接受 T90 10s）。
