# C₄F₇N 检漏仪 — 样件台架验证方案

> 验证目标：**MST-N7M 模组在目标气路流量下 T90 是否 ≤5s**（用户指标），以及串口协议、手温漂移、重复性是否满足整机设计需求。
> 结论触发决策：验证通过 → 开始 PCB 设计；不通过 → 与厂商谈固件定制，或降级为 LARK-1QM（T90 10s）方案。
> 日期：2026-08-20

---

## 一、验证对象与判定标准

| 项目 | 判定标准 | 备注 |
|------|---------|------|
| T90 响应时间 | **≤6s**（对用户 5s 指标留 1s 余量） | 流量 ≥0.5L/min 下实测 |
| 串口输出协议 | 浓度文本/帧格式清晰可解析，输出频率可确认 | 索取厂商协议手册 |
| 输出频率 | ≥1Hz，若能配置 4Hz 更优 | 影响 T90 与显示平滑 |
| 手温漂移 | 30min 手握，浓度漂移 **<2ppm** | 决定手柄隔热设计必要性 |
| 重复性 | 同浓度 5 次测量，CV **<±1.5%** | 与厂商标称 1.5% 对齐 |
| 零点稳定性 | 洁净空气下 10min 零点漂移 <±1ppm | |
| 功耗 | 实测模组稳态电流，与 datasheet 比对 | 修正整机续航估算 |

## 二、台架搭建

```
                    ┌────────────────────────────┐
 标气/空气切换阀 → │ 转子流量计(0.1-2L/min)   │
   (三通+快接)     │   ↓ 硅胶软管               │
                    └────────────────────────────┘
                          ↓
                   ┌──────────────┐
                   │ MST-N7M 模组 │ ← 5V 电源（限流）
                   │  气室进气口   │ ← USB-TTL 接 PC（3.3V TTL）
                   └──────┬───────┘
                          ↓
                   微型隔膜泵（抽吸）
                          ↓
                        排气
```

**关键点**：泵在模组**下游**抽吸（与整机"泵留主机"架构一致），流量计在模组上游，切换阀能快速切换 空气↔标气。

### 器材清单（见《01_样件采购清单》）

MST-N7M ×1 · 5V 无刷隔膜泵 ×1 · 转子流量计 ×1 · USB-TTL ×1 · 硅胶软管/三通/快接 · 气袋 ×2 · C₄F₇N 标气（10/100/1000ppm）· 高纯 N₂ · 5V 可调电源 · 温湿度计

## 三、测试流程

### 步骤 1：模组上电与串口连通（半天）

1. MST-N7M 接 5V 电源（限流 500mA），V+/Gnd 正确（3.0-5.5V 范围）
2. TX/RX 接 USB-TTL（**3.3V 电平，切勿接 5V TTL 烧模组**）
3. 串口工具（如 SSCOM/串口猎人）观察输出，**记录：波特率、输出格式、帧结构、初始预热时间**
4. 确认模组对 0.4-2V 模拟输出（可测）与串口输出的对应关系
5. 向厂商确认：是否有配置命令（输出频率、平均窗口、量程切换 1000/3000ppm）

> ⚠️ 协议手册未到手时，本步只能被动观察输出；**若输出频率不可配置且默认很慢（如 1Hz 且内部长平均），T90 大概率不达标**，需立即联系厂商谈固件定制。

### 步骤 2：气路流量标定（半天）

1. 泵供电 5V，接入气路，调节泵驱动（可串限流电阻或 PWM 预留口）或更换泵
2. 用流量计记录 3 档流量：**0.3 / 0.5 / 1.0 L/min**（覆盖整机设计工作点）
3. 记录各流量下模组气室排气流畅性、是否漏气

### 步骤 3：T90 响应时间测试（1-2 天，核心）

**T90 定义**：浓度从阶跃变化的 10% 上升到 90% 所需时间。

1. 气路稳定抽吸洁净空气，等模组读数归零（零点）
2. 快速切换三通阀 → 通入 **100ppm 标气**，同时启动计时（或 PC 端记录时间戳）
3. 记录读数随时间变化曲线（PC 每 100ms 采样一次串口输出）
4. 计算 T10→T90 时间；重复 3 次取均值
5. 分别在 **0.3 / 0.5 / 1.0 L/min** 三个流量下重复，绘制「流量-T90」曲线
6. 用 10ppm、1000ppm 标气各做一组，确认量程内 T90 一致性（低浓度可能更慢）

**预判**：若 0.5L/min 下 T90 ≤6s → 通过，整机按 ≥0.5L/min 设计流量；若 T90 在 6-10s → 提高流量重测，或与厂商谈固件定制；若 >10s 无法改善 → 换 LARK-1QM 或接受放宽指标。

### 步骤 4：手温漂移测试（半天）

1. 模组稳定在洁净空气中，读数归零记录基线
2. 将模组紧贴手掌（模拟手握），期间手掌温度 32-35°C
3. 每 5min 记录一次读数，共 30min
4. 计算最大漂移 Δppm；**若 >2ppm，手柄设计必须加隔热层 + 板载温度补偿**

### 步骤 5：重复性与零点稳定性（1 天）

1. 同一浓度（100ppm）连续 5 次阶跃测试，记录峰值读数，计算变异系数 CV
2. 洁净空气下连续 10min，记录零点漂移（每 30s 采样）
3. 温湿度记录（设备使用环境 -20~+60°C 宽温，若有条件补做高温 40°C 下重复性）

### 步骤 6：功耗测试（半天）

1. 稳态工作电流（泵不开 vs 泵开）
2. 预热电流峰值
3. 数据用于修正整机 5-6h 续航估算

## 五、验证通过后的行动项

| 通过情况 | 后续动作 |
|---------|---------|
| T90 ≤6s + 协议 OK | ① 锁定 MST-N7M 采购渠道 ② 按 0.5L/min 设计整机气路 ③ 开始 PCB 原理图/布局 |
| T90 6-10s 但可配置 | 与厂商谈固件定制（提高输出频率、缩短平均窗口）→ 复测 → 通过后锁定 |
| 手温漂移 >2ppm | 手柄机械结构增加隔热层设计（发泡聚氨酯/气凝胶） |
| 全部不达标 | 回退备选：LARK-1QM（T90 10s，指标放宽）或 GC5G1（在线式，放弃便携定位） |

## 六、风险提示

1. **标气是最大不可控项**：C₄F₇N 标气供应商少、价格高、交期长。尽早询价；如来不及，先用 SF6 标气做**相对 T90 验证**（气体物理性质不同但 NDIR 响应机理一致，T90 趋势可参考，绝对精度待标气到位后补测）。
2. 模组输出频率若被固件锁死（如固定 1Hz + 20s 平均），T90 无论如何测都 >10s——**协议手册是第一优先级**。
3. 测试期间保持环境温度稳定（±2°C 内），避免温漂干扰 T90 读数。
