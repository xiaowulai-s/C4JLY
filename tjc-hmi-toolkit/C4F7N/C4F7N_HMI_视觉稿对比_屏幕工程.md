# C4F7N HMI · 视觉稿 vs 屏幕工程 差异对比清单

> 对比基准：
>
> - 视觉稿：`C4F7N_LeakDetector/tools/C4F7N_HMI_视觉稿_1024x600_v2.html`（设计目标）
>
> - 屏幕工程：`tjc-hmi-toolkit/C4F7N/config_c4f7n.json`（实际生成的 .HMI，最新 v26）
>
> 说明：统一 1024×600，淘晶驰 7 寸；主控 STM32F103RCT6；传感器 GC5G1(UART)；
> 存储 W25Q16。符号约定：✅一致 ⚠️差异待确认/待修 ❌屏幕工程缺失(相对稿)

## 差异分类与处置建议

### ① 屏幕工程缺失/待修（对应真实功能缺陷）

| 项    | 问题        | 建议修复                                                                    |
| ---- | --------- | ----------------------------------------------------------------------- |
| C-19 | 表格无真正两列对齐 | ✅ 已修：每行拆为 **`tt0-11`(时间text) /** **`np0-11`(浓度text)** 两个控件，两列等宽**每列居中** |
| B-12 | 背光数值不随滑块  | 恢复 `di` 滑块脚本联动 `dv`(但受 15B 限制)，或由 MCU 按滑块 `val` 回写 `dv`                 |
| B-15 | 标定提示无外框   | 给 `cht` 加背景色 bco 或叠加一个面板 text 控件作外框                                     |
| B-9  | 阈值"改不动"   | 依赖固件 `get h.val/l.val` 回读链路，需真机验证；MCU `hmi_on_thr_hi/lo` 已实现补读          |
| C-21 | 统计栏对齐     | ✅ 已修：标签 `xcen=0`(左) / 数值 `xcen=2`(右)，垂直按中线对齐                            |

### ② 视觉稿自身错误（待改稿）

| 项    | 错误               | 应改为                     |
| ---- | ---------------- | ----------------------- |
| D-24 | 主控 C8T6          | **STM32F103RCT6**       |
| D-25 | 探头 MST-N7M/RS485 | **GC5G1 · 数字UART 主动上报** |

### ③ 风格差异（可接受，视验收标准定）

- B-8 阈值字号偏小

- A-7 徽章"ON"字样

- B-11 蜂鸣开关形态（按钮 vs 开关）
