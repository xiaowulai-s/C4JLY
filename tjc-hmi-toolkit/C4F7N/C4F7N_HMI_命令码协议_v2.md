# C4F7N HMI→MCU 交互上报 · printh 单字节命令码协议 (v2)

> 背景：TJC 引擎把脚本行 `L≥16` 的记录硬当 attr 解析 → 越界。因此脚本行必须 ≤15B。
> `print`（Nextion）TJC 不支持；`prints "长关键字"` 超出 15B。改用 TJC 原生 `printh`
> 单字节命令码。MCU 端收 1 字节即触发对应动作（脉冲式上报，无需帧尾）。

## 格式

每条交互在按钮 up 事件写：

```
printh 0A
```

`printh`(6B) + 空格(1B) + `0A`(2B) = **9B ≤ 15B** ✓

MCU 从串口收到非 Nextion 的 1 字节时，按下表分发（0x00\~0xFF 均有效的私有命令）：

| 命令码(hex) | 含义       | 对应交互                  |
| -------- | -------- | --------------------- |
| 0x01     | 重置峰值     | 主页「重置峰值」              |
| 0x11     | 高报阈值     | 设置「高报 +」/「高报 -」（附值见下） |
| 0x12     | 低报阈值     | 设置「低报 +」/「低报 -」       |
| 0x13     | 单位切换     | 设置「单位」ppm↔g/年         |
| 0x14     | 蜂鸣器开关    | 设置「蜂鸣器」               |
| 0x15     | 零点标定     | 设置「零点标定 执行」           |
| 0x16     | 量程标定     | 设置「量程标定 执行」           |
| 0x17     | 恢复出厂     | 设置「恢复出厂」              |
| 0x21     | 曲线 10 分钟 | 历史曲线「10分钟」            |
| 0x22     | 曲线 1 小时  | 历史曲线「1小时」             |
| 0x23     | 曲线 24 小时 | 历史曲线「24小时」            |
| 0x24     | 导出 CSV   | 历史曲线「导出」              |

## 阈值上报（0x11/0x12 后续值）

TJC 每按一次只发命令码。MCU 收到 0x11/0x12 后用 **get 指令回读**高报/低报值：

```
get h.val\xff\xff\xff     # 读高报值 h (0.01ppm×100 → 0~100000)
get l.val\xff\xff\xff     # 读低报值 l
```

或 HMI 在 up 后再 `prints h"` ... 因 15B 限制，**推荐 MCU 主动 get 回读**。

> v2 相比 v1(print 关键字) 变更：交互上报改为 1 字节命令码；MCU 解析器需按字节分发表重构。
> 主控侧见 `c4f7n_hmi_protocol.h` §1a（新增）。

## MCU → 屏幕 下发对象 / 指令明细

> 下发用 Nextion 指令 `obj.attr=value`，尾部须带 `0xFF 0xFF 0xFF` 帧尾；对象短名为唯一事实源（`c4f7n_hmi_protocol.h`）。

### 下发对象

| 对象                                     | 归属页   | 属性      | 说明                         |
| -------------------------------------- | ----- | ------- | -------------------------- |
| `cc`                                   | 主页    | val     | 浓度大字（vvs=2，val=42 显示 0.42） |
| `pv`                                   | 主页    | val     | 峰值（vvs=2）                  |
| `ba`                                   | 主页    | txt     | 均值徽章                       |
| `ps`                                   | 主页    | pco     | 报警色条 9771绿/62689橙/59944红   |
| `p9` `pf` `pt` `pth`                   | 主页    | txt     | T90 / 流量 / 温度 / 阈值 状态行     |
| `h` `l`                                | 设置    | val     | 高 / 低报阈值                   |
| `u`                                    | 设置    | txt     | 单位按钮（"ppm" / "g/年"）        |
| `bb`                                   | 设置    | txt     | 蜂鸣开关（"开" / "关"）            |
| `c0` `c1`                              | 设置    | txt     | 零点 / 量程标定按钮（"执行" / "执行中"）  |
| `mx` `av` `mn` `du` `ct`               | 历史    | txt     | 统计：最大/平均/最小/时长/点数          |
| `wv`                                   | 历史    | add/cls | 波形通道0（`add 0,val` 喂点）      |
| `pst`                                  | 关于    | txt     | 探头状态                       |
| `pc2` `pc2_s1` `pc2_s2` `pc2_s3` `bat` | 各页/关于 | txt     | 电量 "电量N%"                  |

### 通用指令

| 指令             | 说明                  |
| -------------- | ------------------- |
| `page N`       | 切页                  |
| `add 0,val`    | 曲线喂点（val 0\~255）    |
| `cls 0`        | 清空曲线                |
| `dim=N`        | 背光亮度                |
| `get obj.prop` | 回读属性（应答帧 0x70/0x71） |

## 命令码 ↔ 屏幕 up 脚本全明细（v19 实证）

> 唯一事实源：`tjc-hmi-toolkit/C4F7N/config_c4f7n.json`。**命令码与 `c4f7n_hmi_protocol.h` §1 一致。**

| 命令码 | 含义   | 按钮对象 | 归属页 | 按钮 up 脚本（逐行，`\n` 分隔） |
| --- | --- | --- | --- | --- |
| 0x01 | 重置峰值 | `pr` | 主页 | `pv.val=0` / `printh 01` |
| 0x11 | 高报− | `hm` | 设置 | `h.val=h.val-50` / `if(h.val<100)` / `{` / `h.val=100` / `}` / `printh 11` |
| 0x11 | 高报+ | `hp` | 设置 | `h.val=h.val+50` / `if(h.val>1000)` / `{` / `h.val=1000` / `}` / `printh 11` |
| 0x12 | 低报− | `lm` | 设置 | `l.val=l.val-10` / `if(l.val<10)` / `{` / `l.val=10` / `}` / `printh 12` |
| 0x12 | 低报+ | `lp` | 设置 | `l.val=l.val+10` / `if(l.val>1000)` / `{` / `l.val=1000` / `}` / `printh 12` |
| 0x13 | 单位切换 | `u` | 设置 | `printh 13`（暂存于参数，MCU 回写 `u.txt` 文案） |
| 0x14 | 蜂鸣器开关 | `bb` | 设置 | `printh 14`（MCU 回写 `bb.txt`） |
| 0x15 | 零点标定 | `c0` | 设置 | `c0.txt="执行中"` / `printh 15`（标定完成 MCU 回写 `c0.txt="执行"`） |
| 0x16 | 量程标定 | `c1` | 设置 | `c1.txt="执行中"` / `printh 16` |
| 0x17 | 恢复出厂 | `cf` | 设置 | `printh 17` |
| 0x21 | 曲线 10分钟 | `r0` | 历史 | `r0.pic=1` / `r1.pic=0` / `r2.pic=0` / `r0.pco=65535` / `r1.pco=59230` / `r2.pco=59230` / `printh 21` |
| 0x22 | 曲线 1小时 | `r1` | 历史 | `r0.pic=0` / `r1.pic=1` / `r2.pic=0` / `r0.pco=59230` / `r1.pco=65535` / `r2.pco=59230` / `printh 22` |
| 0x23 | 曲线 24小时 | `r2` | 历史 | `r0.pic=0` / `r1.pic=0` / `r2.pic=1` / `r0.pco=59230` / `r1.pco=59230` / `r2.pco=65535` / `printh 23` |
| 0x24 | 导出 CSV | `ex` | 历史 | `ex.txt="导出中"` / `printh 24` |

> **阈值取值由 MCU 主动 `get h.val` / `get l.val` 回读**（`hm/hp`、`lm/lp` 只发命令码，不附值），避免 15B 限制。
