# C4F7N_HMI_v34.HMI ⟷ 视觉稿 v2 · 逐组件核对清单

> **基准**
> - 视觉稿：`C4F7N_LeakDetector/tools/C4F7N_HMI_视觉稿_1024x600_v2.html`（设计目标）
> - 屏幕工程：`tjc-hmi-toolkit/C4F7N/C4F7N_HMI_v34.HMI`（实测产物，v34 = 2026-09-03 15:56）
>
> **核对方式**：`extract-pas` 抽出 4 个页面块 → 解析全部 **251 个对象**（主页45/设置69/曲线83/关于54）的属性与事件脚本 → 与 HTML 稿逐个组件比对。
>
> **字库实测**（读 .zi 文件头 offset+6）：`0.zi=16号`、`1.zi=64号`、`2.zi=16号`、`3.zi=32号`。
> 故工程中 `font=0`→16px、`font=1`→**64px**、`font=3`→32px。模板无 >64 号字库。
>
> **符号**：✅ 符合 │ ⚠️ 部分差异/技术受限 │ ❌ 不符合（需修）

## 零、总体结论

| 项 | 结果 |
|---|---|
| 页面结构（4 页：主页/设置/历史曲线/关于） | ✅ 完全一致 |
| 三段式框架（顶栏 64 / 内容 84–508 / 底栏 74） | ✅ 完全一致 |
| 配色体系（RGB565 逐值比对） | ✅ 高度一致（见 §五） |
| 组件覆盖度 | ✅ 稿中 65 个组件点，工程覆盖 61 个 |
| **完全符合** | **31 项** |
| **部分差异** | **21 项**（多数为 TJC 引擎能力限制，可忽略） |
| **不符合，需修** | **13 项**（含 4 处真实布局/功能缺陷） |

**必须修的 4 个硬伤**：

1. **历史曲线页数据表越界** — `p2D` w=976 横跨全屏，`hc` 浓度列延伸到 x=976，侵入右侧「数据统计」面板（760–1000）216px；`bup/bdn` 翻页按钮也落在右栏。
2. **背光滑块数值不随动** — `di` 滑块 `codesslide` 为空（0 行脚本），拖动后 `dv` 不变。
3. **主页左栏缺面板外框** — 右栏有 `pk`/`pd` 面板底，左栏 readout 区域无任何面板底控件，视觉上是"浮空文字"。
4. **主页栏宽比例反了** — 稿为「宽主区 658 : 窄侧栏 300」，工程为「440 : 460」近似对半。
